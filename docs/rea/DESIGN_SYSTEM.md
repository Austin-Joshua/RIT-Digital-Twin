# RIT Unified Design System & UI Specification

Extracts and defines the canonical visual design patterns shared between the reference IMS and our Digital Twin application.

---

## 1. Core Principles
- **Clarity & Institutional Density**: High-density data presentation suited for academic records, schedules, and administrative ledgers.
- **Brand Identity**: Rajalakshmi Institute of Technology (RIT) navy `#0B2C6B`, gold `#B8860B` / `#FFD700`, with high contrast text for accessibility.
- **Preservation of Digital Twin Capabilities**: Modern responsive layout, dark/light theme switching, and interactive 3D visualizations must live harmoniously with the institutional layout.

---

## 2. Shared Foundations
- **Typography**: Inter / Plus Jakarta Sans.
- **Breakpoints**: Desktop (`>= 1024px`), Tablet (`768px – 1023px`), Mobile (`< 768px`).
- **Surface Elevation**: Subtle cards (`border: 1px solid var(--theme-border)`), rounded corners (`borderRadius: 12px` or `14px`).
